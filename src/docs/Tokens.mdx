export const resolve = (v) => v.replace(/\{([^}]+)\}/g, (_, p) => primitives[p.replaceAll(".", "-")] ?? v);

# Tokens

Tokens come in two layers.

- **Primitives** are raw values: `navy-600`, `space-4`, `radius-md`. Components never use them directly.
- **Semantic tokens** describe a job: `color-action`, `color-text-muted`, `color-danger-bg`. Each theme points them at different primitives.

Edit `tokens/tokens.json`, run `npm run tokens`, and `src/tokens/tokens.css` and `src/tokens/tokens.ts` are regenerated. The build fails if a semantic token points at a primitive that does not exist, or if the dark theme is missing a token the light theme defines.

## Using tokens outside the components

```css
.report-header { padding: var(--hb-space-4); color: var(--hb-color-text-muted); }
```

```ts
import { cssVar } from "harbor-ui";
element.style.borderColor = cssVar("color-border");
```
